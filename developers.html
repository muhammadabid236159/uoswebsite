Muhammad Abid

Core Full Stack Developer & AI Systems Architect
Student, Department of Computer & Software Technology (DCST) • University of Swat

Muhammad Abid is the visionary core developer who spearheaded the entire redesign of the University of Swat digital portal and engineered the intelligent UOS AI Assistant from the ground up. With deep expertise across full-stack web technologies, Abid specializes in advanced AI Chatbot integration (Google Gemini, RAG with university prospectus, real-time context routing), and Firebase Cloud Infrastructure.

His mission is to empower students, faculty, and campus visitors with lightning-fast digital access and autonomous, conversational assistance.

Key Architectural Contributions
  • End-to-end Full Stack Web Architecture
  • AI Chatbot & Google Gemini Integration
  • Prospectus RAG & Knowledge Routing
  • Firebase Cloud, Firestore & Realtime DB
  • FastAPI & Python Microservice Pipelines
  • iPhone 16 Pro Max Native Assistant UI

Aftab Ahmad

MERN Stack Developer & Software Engineer
Student, Department of Computer & Software Technology (DCST) • University of Swat

Aftab Ahmad is a talented software engineer and fellow classmate in the Department of Computer & Software Technology (DCST) at the University of Swat. Sharing the same academic cohort, Aftab specializes in the modern MERN Stack (MongoDB, Express.js, React, Node.js).

With a meticulous focus on responsive design, clean component hierarchy, and scalable API architecture, Aftab is committed to creating polished web applications that simplify user workflows and deliver high-performance interactive experiences across all modern screen resolutions.

Engineering & Development Focus
  • MERN Stack Application Architecture
  • Scalable RESTful API Design with Express
  • Interactive React Component Hierarchies
  • MongoDB Database Modeling & Aggregations
  • Modern JavaScript ES6+ & Asynchronous Workflows
  • Tailwind & Responsive UI Optimization
